# Relay 怎么用

给日常使用者看的。不需要懂代码，也不需要看开发者参考。

---

## 它是什么

Relay 让本机上的应用（邮件、笔记、待办、你自己写的小工具）都能使唤同一个 AI。

好处是：**这个 AI 记得你**。你在一个应用里说过的事，换个应用再问，它仍然知道，不用重新解释一遍。

代价是：**每一个应用都能让 AI 做事**，所以它需要你逐个点头同意。

---

## 第一次：右下角会弹出一个小窗

你第一次打开某个接了 Relay 的应用、并且它要用 AI 时，屏幕**右下角**会弹出一个置顶小窗：

```
应用「某个应用」请求接入 Relay，是否允许？

                     [拒绝]  [允许]
```

这是在问你一件事：**你允许这个应用使用你的 AI 吗？**

- 点「允许」——这个应用以后就能把任务交给 AI。它会拿到一张"凭证"，存在它自己那边。
- 点「拒绝」——它进黑名单，以后**不会再弹窗问你**，也不会再打扰你。

小窗 60 秒没反应会自动关掉，等同于没答应（应用会收到"超时"，可能过一会儿再问一次）。

> 为什么是系统窗口而不是网页弹窗？因为它由操作系统画在你屏幕上，**只有你本人能点**，别的程序没法替你点"同意"。

## 工作区里的 Relay 是什么

安装之后，DSH 左侧会多出一个叫 **Relay** 的工作区，里面默认有一个叫「外部任务」的会话。

- **外部应用的消息都落在这个会话里。** 邮件、待办这些应用发来的任务，都在这里排队、执行。
- **你可以像普通会话一样打开它**，看它处理了什么，也可以直接跟它说话——它同时听得懂你和应用。
- **同目录下有一个 `AGENTS.md`**，是写给 AI 的说明书：这些消息是谁发的、哪些要警惕、回答该返回给谁。你可以打开改，改完下次生效。
- **AI 干活时写的笔记、脚本也在这里**，随时能翻。

位置在 `~/.dsh/relay/workspace`（如果你设过 `DSH_HOME`，就在它下面）。想换个地方，可以改插件配置里的 `workspacePath`。

不想让某个应用碰这个工作区，去「设置 → 应用权限」把它的级别调到 0 就行。

---

## 四个权限级别

允许之后，这个应用默认是**级别 1**。你可以在设置里改。

| 级别 | 名字 | 它看到什么 |
|:--:|---|---|
| 0 | 禁止 | 什么都做不了，也不会再问你 |
| 1 | 每条都问 | 它每发一条消息，都弹一次窗问你 |
| 2 | 只问你不知道的 | 你亲手点出来的操作直接放行；**它自己在后台发的**仍然问你 |
| 3 | 完全信任 | 全部放行，不再弹窗 |

**级别和弹窗的关系，是这套东西里唯一需要记住的事：**

> **你亲手点的** → 级别 2 就不会打扰你。
> **它自己在后台干的** → 级别 2 仍然会问你，只有级别 3 才不问。

所以：如果你觉得某个应用很吵，先看它是"你点了才动"还是"自己偷偷在动"。
前者调到 2 就清净了；后者你调到 2 也没用，它会一直问——那种情况下你要么容忍，要么信任它到 3。

## 在设置里管理

打开 DSH 的 **设置 → 应用权限**，会看到一张表：

```
应用          级别        凭证      操作
inbox-demo    每条都问    已持有    改级别 · 重置凭证 · 删除
某个旧应用     禁止        —        解除禁止
```

能做的事：

| 操作 | 什么时候用 |
|---|---|
| **改级别** | 嫌吵就降，信任就升。立即生效，不用重启 |
| **撤销**（改成 0） | 临时停用。凭证还在，以后想恢复直接调回来 |
| **解除禁止** | 之前点过"拒绝"的应用，想重新给它机会 |
| **重置凭证** | 应用那边凭证丢了或泄露了。旧的立刻失效，级别不变 |
| **删除** | 彻底清掉，等于从没接过入。想再用得重新申请 |

**降级和撤销不需要二次确认，升级需要。** 因为收紧权限不会让你损失什么，放松会。

---

## 关于"完全信任"（级别 3）

这一级别下，AI 能直接读写你机器上的文件、执行命令、上网查东西，**而且不再问你**。

也就是说：一个级别 3 的应用，理论上可以让 AI 在你电脑上做任何事。

所以：

- 只给你自己写的、或者完全信任的应用开级别 3。
- 不确定就先留 1 或 2，用一阵子看看它到底在干什么，再决定。
- 改成 0 随时能停，不需要应用配合。

## 常见问题

**为什么我没操作，它也弹窗了？**
因为那个应用自己在后台发任务（比如每天定时整理邮件）。它在协议里标记的是"应用发起"，不是你发起，所以按规则要问你。

**点了拒绝，怎么反悔？**
设置 → 应用权限 → 找到它 → 解除禁止。然后等它下次申请。

**应用那边说"凭证无效"怎么办？**
在设置里给它「重置凭证」，把新凭证填到应用那边。或者干脆删掉重新接入。

**我不想让某个应用再用，但不想删它的记录？**
把级别改成 0。它会被静默拒绝，也不会再弹窗。

**弹窗一直没出现？**
确认 DSH 正在运行，而且你人是坐在这台机器前的——从另一台电脑远程访问时，弹窗会出现在那台主机上，你看不到。

**这个 AI 能看到我别的应用里的东西吗？**
能。所有接入的应用共用同一个会话，这正是它的用途——但也意味着你给每个应用开了多大的门，要心里有数。
