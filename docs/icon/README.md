# 图标

源文件是 `relay.svg`，其余都是从它导出的固定尺寸位图。**只改源文件**，位图按需重新导出。

| 文件 | 用途 |
|---|---|
| `relay.svg` | 源文件。包的图标（`package.json` 的 `./icon`）用的是根目录的 `icon.svg`，两份内容相同 |
| `relay-1254.png` | 透明背景，1254×1254。README、社交预览、演示文稿 |
| `relay-1254-white.png` | 白底，1254×1254。不支持透明底的平台（微信预览、部分聊天工具） |
| `relay-256.png` | 透明，256。应用列表、商店条目 |
| `relay-128.png` | 透明，128 |
| `relay-64.png` | 透明，64。插件列表可见尺寸 |
| `relay-48.png` | 透明，48 |
| `relay-32.png` | 透明，32。favicon |
| `relay-16.png` | 透明，16。极小尺寸 |
| `relay.ico` | Windows 图标，内含 16/32/48/64/128/256 六种尺寸 |

## 说明

- 图形本身带蓝色圆角底，所以透明版只有四个角是透明的，可以直接放在任何背景上。
- 颜色固定为 `#2563eb`（主体）、`#06b6d4`（鲸鱼）、`#ffffff`（留白），没有渐变和阴影。
- 小尺寸（16/32）下鲸鱼的嘴和眼睛会糊成一块，这是等宽描边的代价；缩小后主要靠蓝青对比识别。

## 重新导出

任何矢量工具都能从 `relay.svg` 导出。若要在此目录重新生成位图，保持整数尺寸并从 1:1 的 viewBox 直接渲染，不要缩放截图——缩放会引入灰边。
